# Происхождение данных

Откуда что взято — важно для юридической части при запуске.

## Картинки карт — `public/cards/*.svg`

- **Колода Райдера-Уэйта-Смита** (Rider-Waite-Smith, 1909; художник Pamela Colman
  Smith, издатель William Rider & Son). Хранятся как векторные обводки
  (`<svg viewBox="0 0 500 878">`, `<path>`-данные).
- **Статус:** оригинальное издание 1909 года — общественное достояние в США и
  большинстве юрисдикций (авторские права истекли). Это самая распространённая
  «дефолтная» колода.
- **Для продакшена:** перед коммерческим запуском стоит перепроверить статус в РФ
  и заменить/подтвердить источник обводок, либо заказать собственную графику в
  стиле сайта. Сейчас это временный ассет.
- `card-back.svg` — рубашка карты, оформлена под палитру сайта.

## Значения карт — `src/data/cards.ts`

- **22 старших аркана** — тексты (прямое/перевёрнутое значение, keywords) написаны
  вручную для проекта, короткие, в нейтральном тоне.
- **56 младших** — генерируются из шаблона: «В контексте {темы масти}: {значение
  ранга}». Темы мастей (`suitTheme`) и значения рангов (`rankMeaning`) — тоже
  авторские, стандартная общая трактовка (масти = стихии, ранги = стадии процесса).
- Это **опорные значения** для ИИ, не финальный текст пользователю. Финальный разбор
  всегда пишет модель под конкретный вопрос.

## Астрология — движок

- Расчёт: `circular-natal-horoscope-js` (npm, MIT). Внутри — своя эфемерида
  (тип Moshier) и база часовых поясов. Никаких внешних API.
- Таблицы достоинств и управителей знаков (`DIGNITIES`, `RULER_OF` в
  `src/lib/natal/compute.ts`) — классическая западная астрология (традиционные
  управители, эссенциальные достоинства семи классических планет).
- Глифы планет и знаков — символы Unicode (`☉☽☿♀♂♃♄♅♆♇ ♈…♓ ☊ ⚸ ⚷ ℞`), рендерятся
  системным символьным шрифтом с фолбэками.

## Геокодинг

- **OpenStreetMap / Nominatim.** Данные © OpenStreetMap contributors, лицензия
  **ODbL**. Бесплатное публичное API с лимитом ~1 req/s и требованием `User-Agent`.
- Для трафика — свой инстанс Nominatim или коммерческий геокодер.

## «Матрица судьбы» — `src/lib/matrix.ts`

- **Метод свой, не канонический.** Дата рождения сводится к старшим арканам
  арифметикой:
  - `dayArc` = день → аркан; `monthArc` = месяц → аркан;
    `yearArc` = сумма цифр года → аркан; `destinyArc` = сумма трёх → аркан.
  - Расширенные точки (`computeMatrixExtras`): линия любви = `day+month`,
    деньги = `month+year`, кармический хвост = `|day−year|`, зона таланта = `day+destiny`.
  - Сведение `reduceToArcana`: пока > 22 — суммируем цифры; 22 → Шут (`a-00`).
- Это **внутренне согласованная нумерология под интерпретацию**, а не октаграммный
  метод Наталии Ладини. Если нужен именно он — это отдельный движок расчёта.

## Шрифты

`next/font/google`: **Playfair Display** (дисплейный сериф) + **Inter** (тело),
сабсеты `latin` + `cyrillic`. Подключены в `src/app/layout.tsx`.
