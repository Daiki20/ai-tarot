# Документация проекта TarvenAI

Карта проекта для того, кто продолжает разработку (и для его AI-ассистента).
Если спросили «расскажи про проект» / «найди, как работает X» — начинать отсюда.

## Что это

Премиальный сервис таро с AI-тарологом. Пользователь задаёт вопрос обычными словами,
выбирает расклад, тянет карты — нейросеть даёт связный разбор. У зарегистрированных
есть натальная карта, которая учитывается во всех разборах, и история раскладов.

**Стек:** Next.js 16 (App Router, Turbopack) · React 19 · Tailwind v4 · PostgreSQL
(Neon) + Drizzle ORM · OpenAI API.

## Быстрые ответы

- **Где база данных?** Neon (облачный PostgreSQL), строка в `.env.local` → `DATABASE_URL`.
  Локально можно поднять свою через `docker-compose.yml`. Схема: `src/lib/db/schema.ts`.
- **Какие внешние API?** OpenAI (разборы), OpenStreetMap Nominatim (геокодер города рождения).
  Больше никаких. См. [EXTERNAL-SERVICES.md](./EXTERNAL-SERVICES.md).
- **Откуда берутся картинки карт?** Векторные обводки колоды Райдера-Уэйта-Смита (1909,
  общественное достояние), `public/cards/*.svg`. Тексты значений написаны вручную в
  `src/data/cards.ts`. См. [DATA-SOURCES.md](./DATA-SOURCES.md).
- **Как считается натальная карта?** Библиотека `circular-natal-horoscope-js` (чистый JS,
  без внешних API). См. [NATAL-CHART.md](./NATAL-CHART.md).
- **Что ещё не готово?** Реальная оплата (сейчас мок), баланс aura (заглушка «0»),
  «взрослая» авторизация. См. [STUBS.md](./STUBS.md).

## Важно перед правкой кода

`AGENTS.md` в корне: это форк Next.js с ломающими изменениями относительно обычной
документации. Перед написанием кода читать `node_modules/next/dist/docs/`.
